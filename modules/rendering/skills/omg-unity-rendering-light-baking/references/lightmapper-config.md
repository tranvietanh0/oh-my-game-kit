# Lightmapper Configuration Reference

## Default Bake Settings

| Setting | Value | Rationale |
|---------|-------|-----------|
| Lightmapper | Progressive GPU | Fast, OpenCL/CUDA accelerated |
| Direct samples | 32 | Good quality for outdoor scenes |
| Indirect samples | 128 | Captures subtle bounce light |
| Environment samples | 128 | Sky/ambient contribution |
| Resolution | 20 texels/unit | Balance quality vs atlas size |
| Max lightmap size | 1024 | Keeps memory reasonable |
| Mixed mode | IndirectOnly | Only baked indirect bounce; realtime shadows stay |
| Directionality | NonDirectional | Cheaper; sufficient for top-down games |

## Prerequisites

- **OpenCL** installed for GPU lightmapper (verify: `clinfo | head`)
- **Static flags** on all environment geometry (`isStatic = true`)
- **Light probes** placed (use `BattlefieldAssemblySetup.PlaceLightProbes()`)
- **UV2 channels** on all static meshes (auto-generated by `EnsureSceneUV2()`)
- **URP Asset** has `m_MixedLightingSupported: 1` (default)
- **Auto-generate OFF**: Entities Graphics disables auto-generate — must bake manually

## Troubleshooting

### Entities invisible after baking
1. Run `Tools/[YourPackage]/Revert Light to Realtime` (reverts + clears cache)
2. Re-enter Play mode
3. If still broken: `git checkout -- <scene>.unity` to restore scene file

### GPU lightmapper fails
1. Check OpenCL: `clinfo | head` — should show your GPU
2. Install driver: `yay -S opencl-nvidia` (NVIDIA) or `opencl-mesa` (AMD)
3. Fallback: Use `Tools/[YourPackage]/Bake Lighting (CPU)` (slower but reliable)

### Lightmap seams on tiles
- Increase `lightmapPadding` (default 2, try 4)
- Ensure tile meshes have proper UV2 (lightmap UVs)
- Use `NonDirectional` mode to reduce seam visibility
